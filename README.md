# Craft Media Hub CRM Enterprise Suite

Fullstack CRM and Business Management platform covering Sales, Marketing, TradeIndia Sync, Store/Inventory, Accounts, HR, Dedicated Employee Field & Calling Desk, Live Geo-Tracking, and Super Admin RBAC.

## 🛠️ How to Start Manually

### Option 1: Double click `run.bat` (Windows)
Runs both Backend and Frontend in separate command windows.

### Option 2: Run via NPM
```bash
# Terminal 1: Backend
cd craftmedia_backend
npm run dev

# Terminal 2: Frontend
npm run dev
```
